# tools

Every SVG on my profile is generated by a script in here. None of it is hand
drawn, which sounds disciplined but is mostly because I tried hand drawing one
and gave up somewhere around the fortieth `<rect>`.

| script | writes | what it is |
|---|---|---|
| `gen_hero.py` | `assets/hero-tui.svg` | the terminal that keeps typing `fastfetch --me` and `fastfetch --machine` at itself |
| `gen_top.py` | `assets/story-terminal.svg` | `lifetop`, an htop where programming is PID 1 and my hobbies are its children |
| `gen_scan.py` | `assets/self-scan.svg` | sdrtop measuring its own source tree, in dBc, because why not |
| `gen_stack.py` | `assets/stack-boot.svg` | an 80 column BIOS POST screen that boots, hands off, and comes up as the stack |

## Running them

```bash
python3 tools/gen_hero.py
```

Standard library only. No node_modules, no lockfile, nothing to install and
nothing to keep patched. I would like this noted, given the rest of my life.

## Things I learned the hard way

**Wider is smaller.** GitHub scales README images down to roughly 890px. I made
one 1000px wide thinking it would be more readable and it came out tinier than
before. The big panels are 880px now, which is the widest they can be without
getting shrunk. Counterintuitive, then obvious, then permanent.

**Fonts have to travel with you.** GitHub serves these files inside an `<img>`,
which blocks every external request, so a linked webfont silently does nothing.
Anything a graphic needs, it has to already be carrying.

**Test with the animation off.** CSS animations do not run in every renderer.
If an element starts at `opacity: 0` and only a keyframe brings it back, it will
be invisible wherever those keyframes are ignored. Ask me how I know. Actually
do not, the answer is a waterfall that was blank for two hours.

## Keeping the numbers honest

`gen_scan.py` has real counts hardcoded in it, so they go stale as sdrtop grows:

```bash
find src -name '*.rs' | xargs cat | wc -l          # lines
grep -rho '#\[\(tokio::\)\?test\]' src | wc -l     # tests
```

Update the `MODULES` table, rerun the script, done. The bar heights are computed
from the line counts, so I cannot quietly round anything up. Which was the idea.
